Problem Statement

Many homeowners struggle to find reliable and timely professionals for everyday household services. The process is often fragmented, slow, and uncomfortable because users have to compare multiple providers, make repeated calls, and track jobs manually. There is a need for a simple digital platform where customers can request services, and administrators can manage requests, service providers, and order status efficiently.

Business System and Modules

This application is designed as a home services business system with two important modules: the User Module and the Admin Module. Together they manage service booking, tracking, updates, and reporting.

U

User Module

Users can create an account, log in, choose a service type, schedule requests, and track the progress of their jobs until completion.

A

Admin Module

Admins can log in, see all service requests, update statuses, assign job progress, and manage the overall workflow of the platform.

S

Service System

The system stores bookings in browser local storage, making the application functional and easy to demo without requiring backend infrastructure.

Login / Signup

Use local storage to create an account or log in to access the different modules of the app.

Why this app matters

The application solves a real-world problem by making service booking faster and more organized. Customers can request help from anywhere, while admins can monitor the full process from user requests to completion. It is built with pure HTML, CSS, and JavaScript to satisfy the project requirement and keep the interface simple, responsive, and easy to demonstrate.
